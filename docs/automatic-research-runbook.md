# Scriptorium 3.4 个人研究运行说明

## 开始使用

配置当前模型后，在项目会话直接提出研究问题。默认“自动”会路由普通对话或研究；“你好”、帮助不调用模型和网络。研究工具菜单仍可选择仅聊天、仅项目材料及专业方法。明确选择材料／选区，或写“仅根据这些材料”，将限制在已有范围。

联网适配复用现有千问密钥与模型配置。目前仅声明官方北京／新加坡旧兼容端点对应的 qwen-plus／qwen-flash 系列支持结构化原生来源；能力接口为 `/api/v2/system/model/capabilities`。其他模型仍可普通生成，但不假装具备联网能力。自定义端点暂不支持原生联网，不能自动推断另一个地址发送密钥。

协议依据：[阿里云联网搜索官方文档](https://help.aliyun.com/zh/model-studio/web-search)，2026-10-25 核查。普通生成沿用兼容接口；来源发现使用 DashScope 原生请求中的 enable_search、search_options.enable_source 和 forced_search，并读取 search_info.search_results。模型声称“已搜索”不算来源证据；空来源必须等待处理。未进行付费连接测试，能力声明是协议适配，不是账号、地域和实际网络可用性的认证。

## 收集和阅读

来源从发现立即入库，按当前会话、类型、获取状态、采用情况搜索／筛选。仅标题、真实搜索摘要、已存正文、原件待识别和访问受限分别呈现。HTML 提取可读文本，同时保存不可变原始响应；PDF／文本进入既有材料、版本、TEI 和证据流程。摘要单独保存并明确标记，后续可重新获取正文，旧摘要引用仍然可定位。

默认 3 次发现、20 个候选、10 个不同来源的正文尝试、20 MiB／份、100 MiB 累计获取额度，另有 4 万 token、6 节点、2 轮修订。失败后传输用量不明时保留预留，界面把已确认下载和未知额度分开。手动重试仍占用总额度。登录／付费不绕过，可保留书目并自行上传合法原文。

自动模式在候选项目材料中按问题相关性选取代表性原文窗口，默认最多约 6000 code point，保存全部窗口的选中／未读状态，并在报告中说明覆盖限制。它不是“已经阅读全部下载材料”。需要严格范围时使用选区／指定材料；大范围会触发已有研究预算决定。没有新增独立搜索服务、OCR 云服务或自动付费抓取。

停止后不会继续启动后续获取；已在途请求可能已经产生消耗。恢复使用已提交的来源、下载对象及导入任务；对无法确定是否完成的网络请求不自动重复，需明确重试。报错和未核验结果不会转为演示成功。开发验收用的演示／合成材料始终标记。

## 数据与升级

新增 Alembic `research_0006`，仅增加来源、关联、收集检查点与联网账本；历史迁移未改写。先备份，再由现有后台启动链执行升级。源 SQLite 和实际用户研究库没有随本轮验收切换。完整备份包括来源快照、原始对象和账本；撤回后来源入口阻断，相关来源内容按原有保留／清理政策处理。

候选仍使用当前用户 NSIS 安装模式；安装本身不自动正式切换旧数据。数据库、API、Worker 和检索沿用 3.3.1 修复，关闭窗口后后台策略不变。默认不要求 Docker、全局 Python／Node／Java。安装与运行疑难继续参考既有本机运行手册。

## 开发与打包

先完成前端构建与后端检查，冻结 Python 和静态文件，再用独立 staging 生成 PyInstaller 后端，并复制到目标架构 sidecar 路径，最后构建 NSIS。不要在 PyInstaller 收集期间更改源码或 web/dist。不要为了覆盖输出文件按端口终止用户数据库。

新接口：消息 tool=auto／network_mode、项目 sources 列表／详情／snapshot／original／actions、intakes 进度与 decisions。旧 ask/chat/research 保持兼容。来源获取只允许公共 HTTP/S、逐跳 DNS 检查并固定连接地址，不执行网页脚本，不允许来源文本改变权限、端点和预算。

本轮不验证服务器部署、学术判断质量、真实付费 Qwen 连接和干净系统安装矩阵。安装包、必要检查与剩余边界见对应验收记录。
