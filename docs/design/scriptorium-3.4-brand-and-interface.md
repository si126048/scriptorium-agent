# Scriptorium 3.4 品牌与界面规范

日期：2026-10-25。本轮使用原创 SVG 图形，未复制参考产品的标志或组件代码。

## 标志

两片错位书页表示同一材料的不同观察位置，中间留白暗示 S。矢量源为 `web/public/brand/mark.svg`，横排字标为 `wordmark.svg`，单色为 `mono.svg`，深底为 `on-dark.svg`。共用 React 入口为 `web/src/components/startup/LogoSVG.tsx`；侧栏、启动、桌面准备界面均使用该入口。

主色 #b75128，正文 #262a27，底板 #f7f5f0，纸张 #fffefa。深底使用浅色标志；单色版使用 currentColor。图形源画板 50×50；四周至少保留 7 个画板单位的留白。独立图形最小 16px，横排字标建议宽度不少于 180px。不得拉伸、旋转、添加描边、阴影或把负空间填实。16／32／512／1024px PNG、Windows ICO、macOS ICNS 和 favicon 均从同一矢量源生成。小尺寸保留整体书页轮廓，不增加文字。

## 界面

共用变量位于 `web/src/features/workspace/design-tokens.css`，工作台布局在 `workbench.css`，来源功能在 `sources.css`。新增功能使用变量，不再新增局部全套颜色覆盖；历史功能样式采用增量归并，未宣称整个旧 CSS 已全部重写。

| 用途 | 规范 |
|---|---|
| UI 正文 | Segoe UI／系统中文无衬线，约 16px |
| 原文 | 可选中文衬线，18px，长行距 |
| 操作重点 | 橙 #b75128；弱背景 #f6e9dd |
| 成功状态 | 绿 #487555，不能映射为橙色 |
| 失败／受限 | 错误文字和状态标签，不能只依赖颜色 |
| 表面 | 暖白面板、浅边框、10px 圆角 |
| 简单反馈／菜单／面板 | 120／180／240ms |

三栏保留；窄屏一次只显示对话或文档。来源不是新的一级导航：从会话来源入口或材料列表打开同一文档区。新来源不会覆盖已打开的原文或文稿。默认研究进度折叠，阶段和来源数持续可见，展开显示范围、用量与决定。

## 可运行的组件示例

- 空项目发送“你好”：本地问候，不能显示材料研究失败。
- 自动研究来源卡：同一面板同时显示全文、摘要、受限状态；采用与已读分开。
- 摘要阅读：橙色来源说明，引用显示“摘要快照”，不伪造原书页码。
- 阶段卡：处理中可停止；失败／取消后可从检查点继续；追加额度按钮明确显示额度。
- 文稿打开后收到来源事件：只更新来源数量，不抢编辑焦点。

启动品牌过场默认 1.5 秒，Esc／Enter 或按钮可跳过；安静／减少动态模式快速进入，不自动开启声音。品牌过场与真实后台健康状态分开。
