## 2. 原则

1. **只从冻结快照迁移。** 今天核对 `data/lacan.db`：`spans` 124,388、`interview_sessions` 157、`runs` 108，而早先只读盘点为 123,849／124／97。中间仍有写入者。在弄清写入者并停写之前，不做任何 `--apply`。
2. **替身不算通过。** S3 用 MinIO（真实对象服务实现），OCR 用真实引擎跑真实/合成样张，安装包要真正构建并安装；跳过项与替身项分别标注。
3. **每项都有命令与证据文件。** 完成标准是“可重跑的命令 + 落在 `output/` 的日志／报告／散列”，不是“代码里存在”。
4. **凭证不进仓库、不进验收记录。** 模型 key、S3 凭证只经环境变量传入。
5. **未执行不填通过。** 缺少引擎、打包器或样本时，保持“待验证”并写明原因。
