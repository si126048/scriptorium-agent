## 4. 运行与回退

详见 [运行手册](../research-service.md)、[架构记录](../adr/0001-research-foundation.md)。

新增服务使用独立 PostgreSQL 库和对象目录；旧 SQLite 始终可用于旧界面。正式迁移前停止旧端写入，完成快照、报告和抽样核验。切换后的新研究数据不会自动同步回旧库，回退前先导出或备份。

本轮为了真实验证，在 `tmp/research-services` 下载并启动了官方 PostgreSQL／Elasticsearch 临时测试实例，使用回环端口 55432、59200。8010 工作台预览仅含本轮原创合成材料及测试笔记，不是已切换的正式研究库。不要把该临时预览作为持久生产部署。

## 5. 未完成项与后续顺序

这些项保留为未完成，不以“有接口”代替完整实现：

1. **真实迁移与业务确认**：审核两套实际库的归属、授权与重复数据，决定正式持久部署后执行迁移与核验。当前工具对失效同意项目保守阻断，不能宣称所有混合授权项目均无损迁移。
2. **方法质量评议**：用合法可用的原著和真实研究案例，完成普通问答、旧多视角与新协议的对照；补充历史来源校验。模型输出结构正确不等于哲学判断正确。
3. **长文研究与重新检验**：当前为单次有界调用，超出材料记为未覆盖；尚未实现自动分批、跨轮预算、反向找反例和连续重检验的完整调度。
4. **研究分支与审查自动化**：可以人工建立分支、异议和回应，并查看独立研究／概念关系列表；没有完整自动红队、节点去重与多轮分支执行器。
5. **文本学扩展**：完整 ODD／Schematron、扫描 OCR、影像区域锚点、复杂手稿与通用 TEI 无损导入导出尚未完成。首版原貌主要通过原件下载查看。
6. **检索扩展**：更多语言分析器、学术词典、书目／时期高级筛选、语义检索和正式性能基准尚待补齐。
7. **专业模块适配**：旧访谈、Persona、分析的原记录可读，旧运行逻辑仍用旧库；没有全部改写成新库业务流程。
8. **部署发布**：S3 适配器、容器实际构建、生产服务管理、HTTPS 及独立研究版安装程序尚未验收；团队账号与实时协作仍不在首版范围。

按用户优先级，下一步先验证真实材料上的阅读／构境体验和正式迁移，再扩展长文重检验与研究分支。以上状态不把整个全面改造计划标记为已完成。
