# Scriptorium 当前状态

更新：2026-10-27 · 3.6.0 纯插件。

## 已落实

- MCP 12 个工具：材料、检索、引文、方法上下文，以及创建论文、章节正文保存、修订读取、恢复与导出。
- 专用本地 SQLite，不依赖原业务 Store；工作区隔离、来源散列和书目/正文区分。
- ACP v1 上下文适配与取消；Codex、Cursor、Claude Code、Qoder、VS Code、Zed、DeepSeek Harness 配置片段。
- 旧独立前后端、安装与后台代码移除；仅保留插件分发。用户实际数据与旧备份不删除。
- README、原创 SVG 品牌页、论文使用指南、迁移说明和插件打包脚本。
- 默认空资料库；本机用户研究样本留在被忽略的输出目录，不随仓库或包分发。

## 尚未覆盖

- ACP 是上下文 Agent，尚无独立模型执行和持续论文生成；论文通过 MCP + 宿主模型完成。
- Codex 原生工具可见性需要重载会话；真实 stdio SDK 验证不等同于所有宿主实测。DSH/Qoder/Zed 等未安装，不计通过。
- PDF/OCR、联网和 DOCX/期刊格式转换依赖宿主工具，插件不内置这些功能。
- 未提供自动学术质量认证、全自动投稿、团队服务或同步。
- 旧访谈、Persona、TopoStyle 等不属于当前插件已迁移能力，历史恢复点见迁移说明。

检查、包散列和未验证项见 [交付记录](../acceptance/plugin-3.6-20261027.md)。不再以旧 GUI 的全量测试数充当插件验收。
